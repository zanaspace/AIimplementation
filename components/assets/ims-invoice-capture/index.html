Invoice Capture & 3-Way Match

The store officer uploads the supplier's invoice or waybill in Receive Asset. CICOD-AI reads the supplier, invoice number, line items, quantities and unit prices. It then matches them against the approved request and the quantity counted at the dock. It also flags a unit price far above the historical price and any invoice that already exists in Payables. One click pre-fills the receipt, and the officer still checks and saves it.

Screen: Assets → Receive Asset / PayablesComponent: <ai-invoice-capture>Endpoint: /ims/invoice-capture

2. How it works

Document intelligence reads the paper. Deterministic rules do the matching, so every flag can be traced to a number.

Capture

The uploaded invoice or waybill (PDF, scan or phone photo) is sent to /ims/invoice-capture with the store and the officer's dock count.

Protect

The gateway removes bank account numbers and signatory phone numbers before the text is stored. Supplier documents stay on the sovereign model and never leave the tenant.

Read

OCR plus a layout model finds the supplier, invoice number, date and line table. Each line is matched to an asset code in the catalogue by name and supplier part number.

Match

Three-way match: request/PO qty vs invoiced qty vs counted qty. The unit price is compared with the 90-day median in Payables, and a supplier + total + asset + date fingerprint finds duplicate invoices.

Output

Extracted fields with a confidence score, a match chip per line, and plain-English flags with the exact figures. Duplicates block the pre-fill.

Confirm & learn

The officer pre-fills, edits counts, holds for I&QA or rejects the read. Every decision goes to /feedback, and corrected fields retrain the extractor for that supplier's layout.

4. How to implement it in Assets (IMS)

Mount (Receive Asset page)

<link rel="stylesheet" href="/ai/components/ims-invoice-capture.css">
<script src="/ai/shared/ai-gateway.js"></script>
<script src="/ai/components/ims-invoice-capture.js"></script>

<ai-invoice-capture history-days="90"
                    outlier-pct="15"></ai-invoice-capture>

<script>
document.addEventListener('ai-invoice-prefill', e => {
  // host page owns the receipt form
  receiveForm.setHeader(e.detail);
  receiveForm.setLines(e.detail.lines);
});
document.addEventListener('ai-invoice-hold', e =>
  iqa.flagForReview(e.detail.invoiceNo, e.detail.reasons));
</script>

Build steps

  1. Collect 200+ past invoices and waybills per major supplier (NCC first) with the receipts keyed from them, as labelled data.
  2. Run the shared Document Intelligence pipeline (OCR + layout) and map line items to asset codes by name, supplier part number and embeddings.
  3. Expose /ims/invoice-capture on the CICOD-AI Gateway: extraction, then match rules against the request, the dock count and Payables history.
  4. Add the component to Receive Asset and wire ai-invoice-prefill to the form store.
  5. Show the same flags as a column in Payables so Costing sees them before approving a price.
  6. Run in suggestion mode for one quarter; track field accuracy and flags confirmed by I&QA.

Controls

  • Feature flag ai.cicod.imsInvoiceCapture in Assets Settings, on/off per tenant.
  • Price-outlier threshold (default 15%) and history window (default 90 days) are set per asset category.
  • A duplicate flag blocks pre-fill; only an I&QA approver can override it, with a reason.
  • Every read, flag and decision is written to Settings → Audit (feature: CICOD-AI Invoice Capture).
  • Price history is only shown to roles that can already see Payables.
