2. How it works

Retrieval-augmented generation over the file's own text. The model can only quote what is in the document, and it says so when the answer isn't there.

Extract

When a file is uploaded or changed, text is pulled from PDF, DOCX, PPTX and XLSX (OCR for scans and images). Each chunk keeps its page, slide or sheet number.

Protect

The gateway reads the Drive classification. Official files may use the cicod-cloud model. Secret (S) and Top Secret (TS) are routed to the on-prem sovereign model only. NIN, BVN and phone numbers are masked in prompts.

Retrieve

For a question, the top chunks are found by embedding and keyword search, and only from files the user has View Access to.

Generate

The LLM writes the summary or answer from those chunks only. Every sentence carries its page reference. With no supporting chunk, it says "not in this document".

Discuss

"@CICOD-AI" in a comment triggers a thread summary or an answer. "Turn into task" extracts the action, due date and owner, and hands it to ECMS routing (E-T1).

Confirm & learn

The user saves the summary, marks answers helpful or wrong, and creates or discards each task. All of it is recorded via /feedback and in the Drive Audit Log.

4. How to implement it in Drive

Mount (file viewer)

<link rel="stylesheet" href="/ai/components/drive-doc-assistant.css">
<script src="/ai/shared/ai-gateway.js"></script>
<script src="/ai/components/drive-doc-assistant.js"></script>

<ai-doc-assistant file="Budget FMLD_1224_V 2.pdf"
  classification="Secret (S)" owner="Prince E"
  size="359.34 KB" tab="summary"></ai-doc-assistant>

<script>
// Row menu: set the file, then open the tab
rowMenu.on('summarise', f => {
  el.setAttribute('classification', f.classification);
  el.setAttribute('file', f.name);
  el.summarise();
});
document.addEventListener('ai-doc-task', e =>
  ecms.createTask(e.detail));
document.addEventListener('ai-doc-summary-save', e =>
  drive.saveDetail(e.detail.file, 'aiSummary', e.detail.summary));
</script>

Build steps

  1. Add a text-extraction step to the Drive upload pipeline (PDF, Office and OCR). Store chunks with page, slide or sheet numbers.
  2. Index chunks per file, with the file's ACL and classification copied on to every chunk.
  3. Expose /drive/doc-assist on the CICOD-AI Gateway, with classification routing to the sovereign model for S and TS.
  4. Add "✦ Summarise" and "✦ Ask this document" to the row menu, and mount the panel in the file viewer.
  5. Add a comments table to Drive for the Discussion tab. Wire ai-doc-task to ECMS Create Task.
  6. Pilot on General Documents and POLICY_DOCUMENTS. Track the helpful rate and citation accuracy before a wider rollout.

Controls

  • Feature flag ai.cicod.driveDocAssistant in Drive Preferences, on/off per tenant and per folder.
  • Minimum answer confidence is 0.5. Below it, the assistant replies "not in this document" instead of answering.
  • Every summary, question and task is written to the Drive Audit Log (feature: CICOD-AI Document Assistant), with the file and classification.
  • Permission trimming: retrieval only uses files the user has View Access to. Top Secret files can be excluded from CICOD-AI entirely by an admin.
