Reads incoming emails and categorizes them (task, spam, or duplicate). It extracts key details and reads attachments automatically. You can review the suggestions and click Create task or Discard.

2. How it works

A classifier sorts the mail. An extractor and OCR pull out the request. Contact matching and the E-T1 router decide where it goes.

Capture

The mailbox sync (IMAP, Microsoft 365, Google Workspace) passes each new email: sender, subject, body and attachments to /ecms/email-triage.

Protect

The gateway removes personal data (NIN, phone, account numbers) from the text sent to the model and checks sender domains against the tenant allow-list. Everything runs on the sovereign model.

Classify

A classifier labels each email as task, FYI, spam or duplicate. Duplicates are found by embedding similarity against open tasks and recent emails from the same contact.

Extract & OCR

An LLM extracts the requester, subject and a two-sentence request summary. OCR reads PDFs and images (invoices, requisitions, photos of errors).

Match & route

The sender is matched to an ECMS contact (or a new one is proposed), and the Smart routing model (E-T1) suggests queue and priority.

Confirm & learn

The officer creates, edits, links or discards. Every choice, including "not spam", is logged via /feedback and used to retrain the classifier each week.

4. How to implement it in ECMS

Mount (Email Integration page)

<link rel="stylesheet" href="/ai/components/email-to-task.css">
<script src="/ai/shared/ai-gateway.js"></script>
<script src="/ai/components/email-to-task.js"></script>

<script type="application/json" id="inbox">
  {{ untriagedEmails | json }}
</script>
<ai-email-triage inbox="#inbox"></ai-email-triage>

<script>
document.addEventListener('ai-email-create-task', e => {
  // host owns task creation
  e.detail.taskId = tasks.createFromEmail(e.detail);
});
document.addEventListener('ai-email-discard', e =>
  inbox.archive(e.detail.emailId));
</script>

Build steps

  1. Extend the mailbox sync so each new email is stored as "untriaged", with its attachments in Drive (Application Documents → ECMS).
  2. Run OCR on attachments during sync and store the text with the file.
  3. Expose /ecms/email-triage on the CICOD-AI Gateway: classifier, extractor, contact matcher, then the E-T1 router.
  4. Add the Triage inbox tab and the per-mailbox "CICOD-AI Triage" switch. Wire the create event to Create Task.
  5. Run in suggestion mode for 4 weeks and track accuracy per category and per mailbox.
  6. Allow auto-create per mailbox only where task accuracy is 95% or higher. Spam is never deleted automatically.

Controls

  • Feature flag ai.ecms.emailToTask in ECMS Settings, plus an on/off switch per connected mailbox.
  • Auto-create threshold is set per mailbox. It defaults to off (suggest only), so an officer always confirms.
  • Every classification, creation, link, discard and override is written to the ECMS Audit Log (feature: CICOD-AI Email Triage).
  • Only members of the mailbox's workgroup see its triage inbox. Attachments keep their Drive classification.
