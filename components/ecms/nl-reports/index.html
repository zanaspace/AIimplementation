Ask for a Report

A report in ECMS needs up to ten filters. With CICOD-AI you describe the report in one sentence and it fills the filters for you. After it runs, ✦ Summarise tells you what the rows show.

Screen: ECMS → Reports → ReportsComponents: <ai-report-ask> · <ai-report-summary>Endpoints: /ecms/reports/nl-filters · /summarise

1. Try it

Same steps as live ECMS: Set Filters → fill the Generate Report dialog → Apply. Try the example "Open billing complaints this month" at the top of the dialog. Then click ✦ Summarise on the results.

2. How it works

1. Understand

The sentence is turned into the dialog's fields: queue, queue type, status, priority, dates and people.

2. Check

Only values that exist in the tenant are used. Anything unclear is left for you.

3. Run

You click Apply. ECMS runs the report as usual, with your permissions.

4. Summarise

A short summary is written from the rows shown: status, type and unassigned work.

4. How to build it

Mount

<!-- top of the Generate Report dialog -->
<ai-report-ask queues="{{queues|join:'|'}}"
    users="{{users|join:'|'}}"></ai-report-ask>

<!-- next to Download on the Tasks card -->
<ai-report-summary source="#report-rows"></ai-report-summary>

<script>
document.addEventListener('ai-report-filters', e =>
  reportFilters.set(e.detail.filters));   // officer still clicks Apply
</script>

Build steps

  1. Add /ecms/reports/nl-filters and /summarise to the CICOD-AI Gateway.
  2. Put the bar at the top of Generate Report and fill the existing filter fields from its result.
  3. Add Summarise next to Download. It reads only the rows the user sees.

API contract

POST /ai/ecms/reports/nl-filters
{ "prompt": "open billing complaints this month",
  "options": { "queues": ["Complaints", …], "users": […] } }
→ { "filters": { "queue": "Complaints",
      "queueType": "Billing Issue", "status": "open",
      "from": "01/09/2026", "to": "29/09/2026" },
    "understood": ["Queue: Complaints", "…"] }

POST /ai/ecms/reports/summarise
{ "rows": [{ "status": "open", "type": "Billing Issue", … }] }
→ { "narrative": "20 tasks shown: 15 open…", "facts": ["…"] }

Controls

  • On/off per tenant: ai.ecms.nlReports.
  • The AI only fills filters. ECMS runs the report with the user's own permissions.
  • Prompts and filled filters are logged in the Audit Log.
