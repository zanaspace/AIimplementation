Exactly where it goes

① LinkOn the Queue label row, right-aligned opposite "Queue *", on /ecms/tasks/new. It sits exactly where the officer has to decide, and nothing else on the screen moves.
② BoxOpens between the card subtitle and the Queue field, so the flow reads top to bottom: describe, then check Queue and Queue Type.
③ ResultFills in the existing Queue and Queue Type selects, then loads the queue's form in the Form card, with Title, Description, Priority and Assign To filled in.
UnchangedThe officer can ignore the button and pick the queue by hand, exactly as today. Submit stays where it is.

How it works

Describe

The officer's text is sent to /ecms/route-task 700 ms after they stop typing.

Protect

The gateway removes personal data (NIN, phone, email) and keeps Secret content on the sovereign model.

Classify

A classifier trained on the tenant's roughly 16k past tasks picks the queue, queue type and priority. New queues fall back to an LLM.

Assign

The assignee is chosen from the queue's resources by shift, skill and lowest open load.

Confirm & learn

Nothing is filled in until Apply. "Not right" and manual changes are fed back to retrain the model every week.

How to implement it in ECMS

Two additions to the existing Create Task page

<!-- 1. On the Queue label row, opposite "Queue *" -->
<button class="aisr-link" id="ai-route-btn">✦ Not sure? Describe it</button>

<!-- 2. Under the card subtitle, above "Queue" -->
<ai-smart-routing trigger="#ai-route-btn" hidden></ai-smart-routing>

<script>
document.addEventListener('ai-route-apply', e => {
  const s = e.detail;             // the page keeps owning its state
  taskForm.setQueue(s.queue);     // loads queue types as today
  taskForm.setQueueType(s.queueType); // loads the form as today
  taskForm.patch({ title: s.title, description: s.description,
                   priority: s.priority, assignee: s.assignee });
});

// 3. On the existing Submit, after ECMS creates the task:
//    tell CICOD-AI what the officer kept or changed. This is the training signal.
taskForm.onSubmitted(task => AIGateway.feedback(s.suggestionId, 'ecms.smart-routing',
  changedFields(s, task).length ? 'submitted-with-changes' : 'submitted-as-suggested',
  { taskId: task.id, changed: changedFields(s, task) }));
</script>
