2. How it works

1. Read

Upload any staff list (Excel, CSV or PDF). Columns are matched to the template, whatever their names.

2. Clean

Spellings are fixed ("Fin & Accts" → Finance & Accounts) and duplicate roles are merged.

3. Match

Departments and roles that already exist are reused, so there are no duplicates. Line managers are worked out from grade.

4. Check

Rows with problems (missing email, repeated IPPIS) stay out until fixed.

3. Benefits

Weeks → hours

Faster onboarding

A new MDA is set up from its staff list in one sitting.

195 roles

No duplicates

New titles are matched to existing roles, e.g. three "Assistant Director … Technical Support" roles become one.

Safe import

Checked first

Problems are caught before an import that can't be undone.

4. How to build it

Mount (Upload Files step)

<script src="/ai/components/setup-wizard-mapper.js"></script>
<ai-org-mapper tenant-roles="195" tenant-departments="106"></ai-org-mapper>

<script>
document.addEventListener('ai-org-import', e => {
  // e.detail.sheet = { Departments, Roles, Users } in template columns
  wizard.setUploadedFile(toXlsx(e.detail.sheet));   // same path as a manual upload
  wizard.preselect(['Departments', 'Roles', 'Users']);
});
</script>

Build steps

  1. Add /ecms/setup/map-org to the CICOD-AI Gateway.
  2. Write the result into 1Gov_ECMS_WORKFLOW_PLANNING_TEMPLATE.xlsx and hand it to the upload step.
  3. Show the pre-import check in the confirmation dialog.

Controls

  • On/off per tenant: ai.ecms.setupWizardMapper.
  • Phone and email are masked before any model call. The file stays in-country.
  • Nothing is imported until the admin confirms. Each import is logged in the Audit Log.
