Explains the Workflow Dashboard in plain words and flags problems, such as a stalled queue or figures that don't match other screens. It stays out of the way: one ✦ Insights button and a small ✦ on each card.

2. How it works

1. Read

Only the counts on the dashboard, with no task text or personal data.

2. Detect

Rules find stalled queues, work piling up and numbers that disagree with All Tasks or Resource Utilization.

3. Explain

An LLM writes two or three sentences. Every number is checked against the source.

4. Learn

Pin, dismiss or mark a gap as known. This tunes the alerts.

4. How to build it

Mount (Workflow Dashboard)

<!-- next to General Filter -->
<ai-dashboard-insights source="#wf-dashboard"
    viewer-role="{{user.role}}"></ai-dashboard-insights>

<!-- on each card -->
<div data-ai-explain="status" data-ai-data='{"open":166,"closed":14}'>
  <h3>Task Status</h3><span data-ai-explain-slot></span> …
</div>
<div data-queue="Order Fulfilment" data-open="11003"
     data-progress="1" data-closed="2">…</div>

<script>
document.addEventListener('ai-insight-focus', e =>
  dashboard.highlightQueue(e.detail.queue));
</script>

Build steps

  1. Add /ecms/dashboard/insights and /explain to the CICOD-AI Gateway.
  2. Mount the button next to General Filter, and add the slot to each card header.
  3. Add an hourly job that compares dashboard figures with All Tasks and Resource Utilization.

API contract

POST /ai/ecms/dashboard/insights
{ "status": { "new": 5, "total": 16116, "open": 166,
              "progress": 24, "closed": 14 },
  "queues": [{ "name": "Order Fulfilment", "open": 11003,
               "progress": 1, "closed": 2 }, …],
  "crosscheck": { "allTasksOpen": 15399, "utilClosed": 157 },
  "role": "admin" }
→ { "anomalies": [{ "severity": "bad",
      "queue": "Order Fulfilment", "title": "…" }],
    "consistency": [{ "source": "Tasks → All Tasks", "title": "…" }] }

POST /ai/ecms/dashboard/explain
{ "metric": "queues", "data": {…} }
→ { "narrative": "…", "facts": ["…"], "queue": "Order Fulfilment" }

Controls

  • On/off per tenant: ai.ecms.dashboardInsights. Alert thresholds are set per tenant.
  • Only counts leave the page. Viewers only see queues they already have access to.
  • Every insight shown, pinned or dismissed is logged in the Audit Log.
