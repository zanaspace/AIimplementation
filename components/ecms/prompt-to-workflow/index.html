Prompt-to-Workflow

Building a new workflow in ECMS usually requires manually clicking through multiple tabs to configure queues, statuses, forms, escalations, and approvals. Now, you can simply describe your business process in one sentence, and the AI will instantly generate a complete, editable draft. It checks for common mistakes automatically and fills out all the setup tabs for your review.

Screen: ECMS → Workflows → Create WorkflowComponent: <ai-workflow-builder>Endpoint: /ecms/workflow/draft

1. Where it goes: live demo

This is a copy of the ECMS Create Workflow wizard. Click the Vehicle repair example (or write your own, e.g. "Leave request: staff submits → HOD approval → HR review → close, escalate after 24h"), click Generate draft, read the checks, then Apply to wizard. Click through the Process, Form, Escalation and Approval tabs to see what was filled. On the Approval tab, click Create to see what happens next: any blocker is flagged with a one-click fix, then the saved workflow is shown step by step. From there you can open My Workflows, or Test it on Create Task with the new form.

2. How it works

The AI understands business processes and converts plain text into a structured, fully configured workflow.

Capture

Your description is processed alongside your organization's existing queues and roles to ensure it aligns perfectly with your setup.

Protect

Any names or private information are stripped out before processing. The AI only sees generic role names and process steps.

Generate

The system intelligently builds the workflow steps. It detects conditions like "if above ₦200k" and translates them into approval rules, and spots time limits like "within 48h" to set up escalation timers automatically.

Check & Correct

Before applying the workflow, the AI double-checks for common errors—like assigning tasks to empty departments, or missing escalation routes.

4. How to implement it in ECMS

Mount (Create Workflow page)

<link rel="stylesheet" href="/ai/components/prompt-to-workflow.css">
<script src="/ai/shared/ai-gateway.js"></script>
<script src="/ai/components/prompt-to-workflow.js"></script>

<ai-workflow-builder></ai-workflow-builder>

<script>
document.addEventListener('ai-workflow-apply', e => {
  const d = e.detail.draft;   // the wizard store owns state
  wizard.process.set({ queue: d.queue, queueType: d.queueType,
                       statuses: d.statuses });
  wizard.form.setFields(d.fields);
  wizard.escalation.set(d.escalation);
  wizard.approval.set(d.approvals);
});
</script>

Build steps

  1. Publish the ECMS workflow model as a JSON schema (queue, queue type, statuses, fields, escalation, approvals).
  2. Expose /ecms/workflow/draft on the CICOD-AI Gateway with schema-constrained output and the tenant catalogue in the prompt.
  3. Write the lint rules: escalation coverage, active users per approver role, end states, duplicate detection.
  4. Add the component above the wizard and wire ai-workflow-apply to the wizard store.
  5. Seed with 20 real MDA processes (vehicle repair, leave, procurement) and measure edits before Create.

Controls

  • Feature flag ai.ecms.promptToWorkflow in ECMS Settings, on/off per tenant.
  • Blockers (e.g. an approver role with no users) must be resolved before Create is enabled.
  • Every generated and applied draft is written to the ECMS Audit Log (feature: CICOD-AI Workflow).
  • Only workflow administrators see the component; drafts can only use roles and departments in this tenant.
