In-Meeting Context Copilot (Live Recap)

During a live recurring meeting (e.g., Weekly Standups, Monthly Board Meetings), this copilot sits in the sidebar. It automatically surfaces the Summary, Key Decisions, and Pending Action Items from the previous meeting in the series. Users can track live ECMS task statuses without leaving the video call, add carried-forward items to the next agenda, and ensure settled decisions aren't re-litigated.

2. How it works

It retrieves past occurrences, checks live ECMS statuses, and uses an LLM to summarise the timeline.

Identify Series

The gateway finds the series from the meeting's recurrence rule. If there is none, it uses embeddings to find past meetings with a similar title and mostly the same attendees in the same room.

Collect Context

It pulls the AI Minutes of Meeting for all included occurrences in the series. It then queries the live ECMS to get the current status of any tracked Action Items.

Protect

The gateway applies the viewer's permissions. Any minute line items tagged as restricted for a specific subset of users are redacted from the recap if the viewer is unauthorized.

Synthesise

An LLM generates a "Since last time" summary to orient the attendees. It identifies decisions that are being brought up again ("re-litigated") and flags action items that have been carried forward across multiple meetings without closing.

Act

Users can instantly create an ECMS task from an untracked action item directly inside the sidebar, or push a carried-forward item onto the agenda for the next meeting.
