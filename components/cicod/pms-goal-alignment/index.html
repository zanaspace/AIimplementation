Goal Alignment Assistant

When an officer drafts their quarterly goals, the assistant checks each one against the departmental goals. It shows which departmental goal each one supports and scores it on SMART. It suggests a rewrite that fixes the gaps while keeping the officer's intent. It also flags departmental goals no one is working on and weightings that don't match the department's priorities. The officer decides what to change.

Screen: PMS → My Goals (assumed)Component: <ai-goal-alignment>Endpoint: /pms/goal-alignment

2. How it works

Embeddings link goals by meaning, rules check SMART quality, and an LLM writes the rewrite and the missing goals.

Collect

The draft goals and weights, the departmental goals and their weights, the officer's role and grade, and the review period are sent to /pms/goal-alignment.

Protect

The gateway checks the officer can see these departmental goals and removes personal data. PMS data counts as staff personal data, so it stays on the sovereign model.

Link

Each goal and departmental goal is embedded, and cosine similarity gives an alignment score. Links below 0.55 aren't shown, so goals aren't forced onto a departmental goal.

Check SMART

Rules and a small classifier check for a concrete deliverable, a number, a realistic target for the time allowed, a link to a departmental goal and a date inside the review period.

Suggest

An LLM rewrites only the goals that fail a check, keeping the officer's numbers and intent. It drafts a goal for each uncovered departmental goal and suggests a weight from the department's priorities.

Confirm & learn

The officer uses or ignores each suggestion. Every decision is sent to /feedback, and the links are saved on the goal for the supervisor and for the appraisal at year end.

3. Benefits to this feature

These are targets. There's no baseline yet, because PMS couldn't be opened during the walkthrough.

100%

Goals linked to department goals

Every submitted goal is traceable to a departmental goal. That link is what makes the year-end appraisal and department reporting meaningful.

0 gaps

No departmental goal left uncovered

The Director can see straight away whether a departmental goal has no one working on it, before the quarter starts rather than at year end.

−60%

Fewer goals sent back

Supervisors spend less time returning vague goals like "improve customer service", because they arrive already SMART.

Fairer reviews

Measurable from day one

Goals with numbers and dates can be scored from ECMS and Assets data at appraisal time. This feeds the Appraisal Copilot's evidence.

4. How to implement it in PMS

Mount (My Goals page)

<link rel="stylesheet" href="/ai/components/pms-goal-alignment.css">
<script src="/ai/shared/ai-gateway.js"></script>
<script src="/ai/components/pms-goal-alignment.js"></script>

<ai-goal-alignment source="#goal-form"
                   dept-goals="#dept-goals"
                   department="Administration"
                   period="Q4 2026"></ai-goal-alignment>

<script>
el.addEventListener('ai-goal-rewrite', e =>
  goals.update(e.detail.index, { text: e.detail.text }));
el.addEventListener('ai-goal-link', e =>
  goals.update(e.detail.index, { deptGoalIds: e.detail.deptGoalIds }));
el.addEventListener('ai-goal-add', e => goals.add(e.detail));
</script>

Build steps

  1. Add a departmental goals record to PMS (id, text, weight, period, owner) if it doesn't exist yet. The Director enters them each quarter.
  2. Add a deptGoalIds[] field to each personal goal, so the links are stored.
  3. Build /pms/goal-alignment on the AI Gateway: embeddings, then SMART rules, then an LLM to rewrite and suggest. Use the sovereign model only.
  4. Build an evaluation set: 300 past goals labelled by HR for SMART quality and the correct departmental goal.
  5. Mount the component on My Goals and pass a summary to the supervisor's approval screen.
  6. Pilot with one department for one quarter. Measure how many goals are sent back and how many departmental goals are left uncovered.

Controls

  • Feature flag ai.cicod.pmsGoalAlignment, on or off per tenant and per review cycle.
  • Suggestions only. Nothing changes a goal unless the officer clicks. Once a supervisor approves goals, they're locked.
  • The link threshold (default 0.55) is set per tenant, so weak links aren't counted as coverage.
  • Every check and decision goes to the PMS audit log (feature: CICOD-AI Goal Alignment).
  • An officer only sees their own department's goals. A supervisor sees their team's alignment summary, not other teams'.
