CICOD · S7 · Phase 2

Public Sentiment & Feedback Analyzer

CICOD-AI reads every citizen submission: Paperless Service Portal "Engage Us" requests, public webforms, feedback forms, emails and WhatsApp messages, in English and Nigerian Pidgin. It scores each one's sentiment and groups the complaints into systemic issues. It also spots issues that are spiking. Each week it writes an Executive Sentiment Report, for example "58% of complaints this week were about the online payment gateway failing", with a recommended action for each issue that becomes an ECMS task in one click.

2. How it works

Each submission is scored once as it arrives. Issues are found by grouping similar complaints, not from a fixed list, so new problems show up without anyone configuring them.

Collect

Engage Us submissions, public webforms, feedback forms (e.g. PARTICIPANT EVALUATION), email-to-task and WhatsApp messages are sent to /portal/sentiment with their queue and channel.

Protect

Names, phone numbers, emails, NINs and tracking IDs are removed before any text is stored for analysis. Citizen data stays on the sovereign model.

Score sentiment

A multilingual sentiment model (English, Pidgin, Hausa, Yoruba and Igbo) gives each submission a score from −1 to +1. The sentiment index is the share positive minus the share negative, from −100 to 100.

Find issues

Embeddings of the negative submissions are grouped each night, and an LLM names each group ("Online payment gateway failing"). A spike is when the last 3 days run at 2× or more the daily rate of the previous 2 weeks.

Write the report

An LLM writes the headline, summary and a recommended action for each issue, using only the computed figures. Quotes are real submissions with personal details removed.

Act & learn

Officers create ECMS tasks from recommendations or skip them. When the task closes, the next reports show whether that issue's complaints went down.

3. Benefits to this feature

These are targets. The baselines come from the public queues (Complaints held 2,248 open tasks on 27 Sep 2026).

Days → hours

Systemic issues found early

A failing payment gateway shows up as a spike within a day, not after weeks of individual complaints sitting in the Complaints queue.

1 page

Leadership sees the citizen's view

The Perm Sec gets a plain-English weekly summary instead of 2,000 unread tickets.

Fix the cause

One fix, many complaints closed

A single IT task for the payment gateway resolves the cause of dozens of complaints, instead of each one being answered separately.

+20 pts

Sentiment index target

Track whether actions work: the index and each issue's share are compared week on week.

Fraud

Scam alerts sooner

Reports of people posing as staff are grouped and escalated to Fraud and Risk Management, with a Verify Staff alert for the public.

4. How to implement it

Mount (Reports → Citizen Sentiment)

<link rel="stylesheet" href="/ai/components/sentiment-analyzer.css">
<script src="/ai/shared/ai-gateway.js"></script>
<script src="/ai/components/sentiment-analyzer.js"></script>

<ai-sentiment-report period="week" queue="all"></ai-sentiment-report>

<script>
el.addEventListener('ai-sentiment-task', e =>
  ecms.tasks.create({ ...e.detail, source: 'CICOD-AI Sentiment' }));
el.addEventListener('ai-sentiment-send', e =>
  inmail.send({ to: 'Perm Sec + Directors', subject:
    'Weekly citizen sentiment: ' + e.detail.headline,
    body: e.detail.summary }));
</script>

Build steps

  1. Stream new public submissions (portal, webforms, feedback forms, email-to-task, WhatsApp) to the AI Gateway with queue, channel and timestamp.
  2. Score sentiment as each one arrives and store only the score, the redacted text and the embedding.
  3. Run a nightly job that groups the negative submissions into issues, names them and computes shares and spikes.
  4. Build /portal/sentiment to return the report for a period and queue, with an LLM-written headline and summary.
  5. Add the Citizen Sentiment tab to Reports, a card on the Workflow Dashboard, and the Monday InMail schedule.
  6. Validate with communications officers: check a sample of 200 submissions by hand for sentiment and issue accuracy each month.

Controls

  • Feature flag ai.cicod.sentimentAnalyzer, set per tenant. The recipient list and send time are tenant settings.
  • Personal details are removed before storage. Quotes never include names, phone numbers, emails, NINs or tracking IDs.
  • Issue names and actions are suggestions. Tasks are only created when an officer clicks.
  • Individual citizens are never scored or profiled. The report only works with groups of submissions.
  • Each report, task and send goes to the ECMS Audit Log with the model version.
