CICOD-AI Daily Brief

Today the Workspace Home greeting only counts things: "You have 0 approvals, 0 tasks and 0 new files awaiting you." The CICOD-AI Daily Brief reads the same approvals, tasks, shared files, meetings and CICOD Mail notifications and turns them into a ranked list of what to do first. It flags SLA breaches, prepares the next meeting and re-orders the Needs you today cards. The user opens, snoozes or accepts every item.

2. How it works

A scoring model decides the order and an LLM writes the sentences. The model never sees more than the user can already open.

Capture

The page sends the user's open approvals, tasks and workflows (ECMS), unread CICOD Mail notifications, CICOD Drive files pending acceptance and today's Conference meetings to /workspace/daily-brief.

Protect

The gateway sends titles and metadata only, never document bodies. Personal data is redacted. Items marked Secret are summarised on the sovereign model and shown by title only.

Score

Each item gets a score from SLA hours left (the E-T3 SLA-risk model), the sender's grade level from ECMS Users & Roles, and consequence (repeat complaint, payment, blocks a meeting you chair).

Write

An LLM writes the headline, one line of reasoning per item and three meeting-prep points taken from the previous minutes in MINUTES_OF_MEETINGS.

Show

The top 5 items get Open and Snooze. Everything else is grouped into one line. The Needs you today cards get a proposed order and P1/P2/P3 badges.

Confirm & learn

Open, Snooze, Apply order and Not useful are each sent to /feedback. Items the user opens first teach the ranking weights for that user's role.

4. How to implement it in Workspace

Mount (Workspace Home)

<link rel="stylesheet" href="/ai/components/daily-brief.css">
<script src="/ai/shared/ai-gateway.js"></script>
<script src="/ai/components/daily-brief.js"></script>

<script type="application/json" id="db-feed">
  [ /* approvals, tasks, files, meetings, mail */ ]
</script>
<ai-daily-brief feed="#db-feed" user="Prince"></ai-daily-brief>

<script>
document.addEventListener('ai-brief-reorder', e =>
  needsYouToday.setOrder(e.detail.order));
document.addEventListener('ai-brief-open', e =>
  router.open(e.detail.item.app, e.detail.item.id));
</script>

Build steps

  1. Add a Home feed endpoint that returns the user's open approvals, tasks, workflows, pending shared files, today's meetings and unread notifications, with SLA timers.
  2. Reuse the E-T3 SLA-risk model for hours-to-breach. Add grade level from ECMS Users & Roles.
  3. Expose /workspace/daily-brief on the CICOD-AI Gateway: score, then LLM wording, then meeting prep from the last minutes.
  4. Replace the greeting card with the component. Wire ai-brief-reorder to the Needs you today cards.
  5. Pilot with Directors and Heads of Unit for 4 weeks. Compare SLA breaches with a control group.

Controls

  • Feature flag ai.cicod.dailyBrief in Administration, on/off per tenant and per role.
  • SLA-breach threshold defaults to 6 h and is set per tenant. The Needs you today order only changes when the user clicks Apply.
  • Every brief, Open, Snooze and Apply is written to the Workspace audit log (feature: CICOD-AI Daily Brief).
  • Permission trimming: the feed is built with the user's own token, so the brief can't mention an item the user can't open.
