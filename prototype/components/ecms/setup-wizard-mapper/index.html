Setup Wizard CICOD-AI Mapper

Setting up a new organization in CICOD usually requires manually typing in every department, job role, employee, and manager from a messy spreadsheet. The Setup Wizard Mapper automates this process. It reads any staff list spreadsheet, automatically matches the columns, fixes inconsistent spellings (like "Fin & Accts" to "Finance"), merges duplicate roles, and figures out who reports to whom. The administrator simply reviews the suggestions and clicks import to instantly build the organization's structure.

2. How it works

Rules and fuzzy matching do most of the work. An LLM only handles titles the rules can't place, and every row gets a confidence score.

Capture

The uploaded Excel, CSV or PDF is converted to rows (PDF tables via document intelligence). The header row and the tenant's existing roles and departments are sent to /ecms/setup/map-org.

Protect

Phone, email and NIN columns are detected and masked before any model call. The file stays in the tenant's Drive, and the sovereign model is used.

Map & normalise

Column headers are matched to CICOD fields. executive abbreviations are expanded ("Asst. Dir." → Assistant Director), and department spellings are grouped.

Deduplicate roles

Token similarity with a rank guard ("Chief" ≠ "Assistant Chief") clusters titles from the file with the tenant's 192 roles. The admin ticks which merges to apply.

Infer line managers

A "Reports To" column is used when present. Otherwise the next grade up in the same department is proposed. Ties and department heads below GL 15 are flagged.

Confirm & learn

Rows under 80% are held back until fixed. Column changes, merge choices and row fixes go to /feedback and extend the tenant's abbreviation list.

4. How to implement it in ECMS

Mount (Setup Wizard page)

<link rel="stylesheet" href="/ai/components/setup-wizard-mapper.css">
<script src="/ai/shared/ai-gateway.js"></script>
<script src="/ai/components/setup-wizard-mapper.js"></script>

<ai-org-mapper tenant-roles="192"></ai-org-mapper>

<script>
document.addEventListener('ai-org-import', async e => {
  const d = e.detail;        // the host performs the import
  await api.departments.upsert(d.departments);
  await api.roles.merge(d.merges);
  await api.users.bulkCreate(d.users);
  wizard.markDone(['departments', 'roles', 'users']);
});
</script>

Build steps

  1. Build the abbreviation and rank dictionary with HR (Asst., Dir., Prog., GL, CSO…).
  2. Expose /ecms/setup/map-org: file-to-rows, column mapping, normalisation, clustering, line-manager inference.
  3. Add a "merge roles" API that moves users and permissions to the canonical role and suspends the old ones.
  4. Mount the component in the Setup Wizard and wire ai-org-import to the bulk APIs.
  5. Run it on cicod's own 192 roles first; review the proposed merges with the admin team.

Controls

  • Feature flag ai.ecms.setupWizardMapper in ECMS Settings, on/off per tenant.
  • Import threshold: rows under 80% confidence are held back until an admin fixes them.
  • Every import, merge and row fix is written to the ECMS Audit Log (feature: CICOD-AI Setup) and can be undone per batch.
  • Only SUPER ADMIN users see the mapper; role merges never grant more permissions than the canonical role has.
