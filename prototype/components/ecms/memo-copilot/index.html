Memo Copilot

Turns an officer's bullet points into a properly formatted official executive memo: Ref No, Date, To / Through / From, SUBJECT in capitals, numbered paragraphs, the amount in figures and words, and a Recommendation. Select any sentence to rewrite it as Formal, Concise, For Hon. Minister or with grammar fixed. A chip also suggests the classification (Official / Confidential / Secret, E-M7) and says why. The officer places every change.

Screen: ECMS → Memos → Create MemoComponent: <ai-memo-copilot>Endpoint: /ecms/memo/draft · /rewrite · /classify

(2) Highlight the rough sentence in the memo and pick a rewrite from the pop-up. (3) Type "salary arrears" or "national security" in the memo and watch the classification chip change.

2. How it works

An LLM fills the MDA's own memo template. Rewrites use the same model with a style instruction, and a small classifier checks sensitivity as the officer types.

Capture

The officer's bullet points, the logged-in user's role and department, and the MDA short name are sent to /ecms/memo/draft. For rewrites, only the selected text is sent.

Protect

The gateway redacts NIN, BVN, phone numbers and emails before the prompt. Text the classifier marks Confidential or Secret is only sent to the sovereign model hosted in-country.

Draft

The model fills the MDA memo template (Ref No, Date, To/Through/From, SUBJECT, numbered paragraphs, Recommendation). A style guide based on the enterprise Rules and Financial Regulations supplies the phrasing ("may wish to kindly approve"). Amounts are written in figures and words by code, not by the model.

Rewrite

Four fixed styles: Formal, Concise, For Hon. Minister (third person, "the Ministry"), and Fix grammar. Each result lists what changed.

Classify

A sensitive-content classifier suggests Official, Confidential or Secret and quotes the words that triggered it, so the officer can judge the suggestion.

Confirm & learn

Nothing enters the memo until the officer clicks Replace, Insert or Apply. Every accept, reject and edit goes to /feedback, and the draft is marked "CICOD-AI-generated" until a human edits and publishes it.

4. How to implement it in ECMS

Mount (Create Memo page)

<link rel="stylesheet" href="/ai/components/memo-copilot.css">
<script src="/ai/shared/ai-gateway.js"></script>
<script src="/ai/components/memo-copilot.js"></script>

<ai-memo-copilot editor="#memo-body"
                 from="Director (ICT)"
                 mda="CICOD"></ai-memo-copilot>

<script>
// the editor stays owned by the host page
on('ai-memo-insert', e => editor.setContent(e.detail.html, e.detail.mode));
on('ai-memo-replace-selection', e => editor.replaceRange(e.detail.range, e.detail.text));
on('ai-memo-classify', e => memoSettings.set('classification', e.detail.level));
</script>

Build steps

  1. Collect 3–5 approved memo templates per MDA (letterhead, Ref No pattern, sign-off) and store them in Memo Settings.
  2. Write the style guide prompt from the enterprise Rules and Financial Regulations; add number-to-words and Ref No generation as code.
  3. Expose /ecms/memo/draft, /rewrite and /classify on the CICOD-AI Gateway.
  4. Mount the panel in the Create Memo editor and wire the three events to the editor API and Settings.
  5. Pilot with two departments; track how much of each draft is kept unchanged at publish.

Controls

  • Feature flag ai.ecms.memoCopilot in ECMS Settings, on/off per tenant.
  • The classification chip only suggests. Publishing a Secret memo still needs the officer's own choice in Settings.
  • Every draft, rewrite and classification decision is written to the ECMS Audit Log (feature: CICOD-AI Memo).
  • The "Through" chain is only suggested from roles the author can address; drafts never include content from files the author can't open.
